# 文本规范化与字段抽取技术说明

- **版本**：v0.1
- **日期**：2026-09-07
- **对应工具**：`employ-guard parse-resume`
- **产品**：[产品说明 §4.7a](../01-product/001_prd_就业守护助手产品说明.md)
- **提示词位置**：`src/employ_guard/parse_resume.py` 中 `SYSTEM_PROMPT`

## 1. 锁定结论

| 项     | 口径                                                                                                  |
| ------ | ----------------------------------------------------------------------------------------------------- |
| 输入   | PDF（须已有 `{stem}.resume.md`）或简历 Markdown / 文本                                                |
| 规范化 | **默认 LLM** 整理 Markdown 结构（不改字义）；失败可回退规则；测试可注入                               |
| 说明   | 装饰条 / 分栏 / 异形标题靠模型泛化；页图仍以 `check-layout` 为准；`read-resume` 仍不擅自拼折行（R2b） |
| 抽取   | LLM 抽字段；缺年龄但有出生年时规则补「当年−出生年」；性别等可空；不完整标 `parse_incomplete`          |
| 输出   | `{stem}.resume.norm.md`；`{stem}.parsed.md` / `{stem}.parsed.json`                                    |
| 终端   | 打印姓名、岗位类表述、段数摘要；不完整时黄字提示；**退出码 0**（写出即可）                            |
| 编排   | **可单独跑**；挂入 `resume` 见看板 R23                                                                |
| 不做   | 不判能不能投；不评排版；不因缺性别判硬伤；抽取失败说明原因退出码 `1`，不得写成不能投                  |

## 2. 检查怎么实现

| 编号           | 实现方式                  | 说明                                                           |
| -------------- | ------------------------- | -------------------------------------------------------------- |
| **normalize**  | **LLM**（默认可回退规则） | 整理 Markdown 结构 / 折行 / 章节；**不改字义**；不是页图查排版 |
| **fields**     | **LLM**                   | 姓名、联系方式、`target_role`、技能、工作、项目、教育、自评    |
| **incomplete** | **规则**                  | 姓名与工作、项目皆空 → `parse_incomplete=true`                 |
| **age 补全**   | **规则**                  | 无年龄但有出生年 → 当年 − 出生年                               |

## 3. 失败约定

| 情况             | 行为                                    |
| ---------------- | --------------------------------------- |
| 无简历文本等     | 失败说明，退出码 `1`                    |
| 写出（含不完整） | 退出码 `0`；报告标明 `parse_incomplete` |
