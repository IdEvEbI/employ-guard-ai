# 项目审阅技术说明

- **版本**：v0.1
- **日期**：2026-09-04
- **对应工具**：`employ-guard review-projects`
- **产品**：[产品说明 §4.7](../01-product/001_prd_就业守护助手产品说明.md)
- **书面口径**：[005 项目审阅口径](../04-standard/005_project-review_项目审阅口径.md)
- **提示词位置**：`src/employ_guard/review_projects.py` 中 `SYSTEM_PROMPT`

## 1. 锁定结论

| 项     | 口径                                                                     |
| ------ | ------------------------------------------------------------------------ |
| 输入   | PDF（须已有 `{stem}.resume.md`）或简历 Markdown / 文本                   |
| 看什么 | **只看文本**；可选岗位说明                                               |
| 输出   | `{stem}.projects.md` / `{stem}.projects.json`                            |
| 档次   | 每项目 **含金量**、**难度**：高 / 中 / 低（`high` \| `mid` \| `low`）    |
| 终端   | 打印主项目数与各档摘要；**退出码 0**（成功写出即可）                     |
| 编排   | **独立工具**；默认不挂入 `resume`；不进 `--triage`                       |
| 不做   | 不判能不能投；不评排版；**不做薪资**；不打百分制；不另发明「好项目」标准 |

报告须声明：审阅档不替代合格线；不含薪资匹配。

## 2. 检查怎么实现

| 编号                | 实现方式 | 说明                                          |
| ------------------- | -------- | --------------------------------------------- |
| **主项目**          | **LLM**  | 识别 1～3 个；标注 primary / secondary        |
| **value_tier**      | **LLM**  | 含金量档；对照 005 §3（对齐 003 H2/H4/H5/H6） |
| **difficulty_tier** | **LLM**  | 难度档；对照 005 §4（对齐 003 H3/H7）         |
| **evidence**        | **LLM**  | 各档一两句依据；须能在简历找到对应表述        |
| **fixes**           | **LLM**  | 每项目 ≤2 条可执行改法                        |

LLM：OpenAI 兼容 Chat Completions；JSON 失败时按策略重试。复用 `resolve_resume_text`。

## 3. 失败约定

| 情况         | 行为                 |
| ------------ | -------------------- |
| 无简历文本等 | 失败说明，退出码 `1` |
| 跑通并写出   | 退出码 `0`           |

## 4. 测试

单元测试注入假的 projects assessor；真实密钥与真实简历不进 Git。
