# 判能不能投技术说明

- **版本**：v0.1
- **日期**：2026-09-02
- **对应工具**：`employ-guard judge-resume`
- **标准**：[004 简历合格线 §2](../04-standard/004_resume-bar_简历合格线.md)
- **提示词位置**：`src/employ_guard/judge_resume.py` 中 `SYSTEM_PROMPT`

## 1. 锁定结论

| 项     | 口径                                                                           |
| ------ | ------------------------------------------------------------------------------ |
| 输入   | PDF（须已有 `{stem}.resume.md`）或简历 Markdown / 文本                         |
| 看什么 | **只看文本**；不读页图，不混排版结论                                           |
| 输出   | `{stem}.judge.md` / `{stem}.judge.json`；合格线与水平线分栏；存疑单独列出      |
| 终端   | 达标打印「内容达标」+ 水平线高/中/低摘要；未达标打印「内容未达标」，退出码 `2` |
| 不做   | 不评排版、不出练习题、不打百分制分数                                           |

## 2. 检查怎么实现

| 编号       | 实现方式                        | 说明                                                                                                |
| ---------- | ------------------------------- | --------------------------------------------------------------------------------------------------- |
| **C1～C9** | **LLM** 读文本                  | 对照 004 §2；`doubtful` 不自动判未合格                                                              |
| **C5**     | **LLM + 规则**                  | 多项目一律「项目负责人」由规则强制存疑                                                              |
| **C6**     | **LLM + 规则**                  | 离谱指标 / 难辩护选型与规模 → 存疑（003 S19）；规则覆盖小模型扛重生成、框架并用写糊、向量量级过小等 |
| **C7**     | **LLM + 规则**                  | 互算不通存疑；**结束年月晚于检查当日**由规则强制存疑（003 S18）                                     |
| **H1～H8** | **LLM + 规则封顶**（仅全 C 过） | 输出高/中/低；C6 存疑则 H4 封顶中；C5 角色注水则 H5 封顶中；无「至今」、技术清单无入口等规则封顶    |

LLM：OpenAI 兼容 Chat Completions；默认 `LLM_MODEL`（见 `.env`）。DeepSeek V4 默认关闭 `thinking`，避免 `content` 为空；优先 `response_format: json_object`，`max_tokens` 8192。若返回空或 JSON 非法，按策略重试（加强 user 提示 → 关闭 json 模式），最多 3 次。用户消息带「检查当日」日期。分项 `note` 须为人话完整句；实现侧会去掉模型误写的 `doubtful=true` 等字段名。

## 3. 失败约定

| 情况             | 行为                                     |
| ---------------- | ---------------------------------------- |
| 无简历文本等     | 失败说明，退出码 `1`                     |
| 跑通但未过合格线 | 写出报告；终端「内容未达标」；退出码 `2` |
