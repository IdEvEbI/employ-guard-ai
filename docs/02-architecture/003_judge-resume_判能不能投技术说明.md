# 判能不能投技术说明

- **版本**：v0.1
- **日期**：2026-09-02
- **对应工具**：`employ-guard judge-resume`
- **标准**：[004 简历合格线 §2](../04-standard/004_resume-bar_简历合格线.md)
- **提示词位置**：`src/employ_guard/judge_resume.py` 中 `SYSTEM_PROMPT`

## 1. 锁定结论

| 项     | 口径                                                                           |
| ------ | ------------------------------------------------------------------------------ |
| 输入   | PDF（须已有 `{stem}.resume.md`）或简历 Markdown / 文本                         |
| 看什么 | **只看文本**；不读页图，不混排版结论                                           |
| 输出   | `{stem}.judge.md` / `{stem}.judge.json`；合格线与水平线分栏；C7 等存疑单独列出 |
| 终端   | 达标打印「内容达标」；未达标打印「内容未达标」及未过项，退出码 `2`             |
| 不做   | 不评排版、不出练习题、不打百分制分数                                           |

## 2. 检查怎么实现

| 编号       | 实现方式             | 说明                                                  |
| ---------- | -------------------- | ----------------------------------------------------- |
| **C1～C9** | **LLM** 读文本       | 对照 004 §2；`doubtful` 不自动判未合格（C7、C8 存疑） |
| **H1～H8** | **LLM**（仅全 C 过） | 未过合格线时不写水平线排序结论                        |

LLM：OpenAI 兼容 Chat Completions；默认 `LLM_MODEL`（见 `.env`）。DeepSeek V4 默认关闭 `thinking`，避免 `content` 为空；优先 `response_format: json_object`，`max_tokens` 8192。若返回空或 JSON 非法，按策略重试（加强 user 提示 → 关闭 json 模式），最多 3 次。

## 3. 失败约定

| 情况             | 行为                                     |
| ---------------- | ---------------------------------------- |
| 无简历文本等     | 失败说明，退出码 `1`                     |
| 跑通但未过合格线 | 写出报告；终端「内容未达标」；退出码 `2` |
