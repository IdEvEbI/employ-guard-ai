# 基础信息检测技术说明

- **版本**：v0.2
- **日期**：2026-09-08
- **对应工具**：`employ-guard check-profile`
- **产品**：[产品说明 §4.3b](../01-product/001_prd_就业守护助手产品说明.md)
- **书面口径**：[003 S1](../04-standard/003_resume-standard_简历书写标准.md) / [004 C1](../04-standard/004_resume-bar_简历合格线.md)
- **提示词位置**：`src/employ_guard/check_profile.py` 中 `SYSTEM_PROMPT`

## 1. 锁定结论

| 项     | 口径                                                                                            |
| ------ | ----------------------------------------------------------------------------------------------- |
| 输入   | PDF（须已有 `{stem}.resume.md`）或简历 Markdown / 文本；**优先**同目录 `resume.norm` + `parsed` |
| 看什么 | **首页基本信息**是否有岗位类表述；不强制「应聘岗位 / 求职意向」四字                             |
| 不算过 | **工作经历抬头岗位名**、项目 / 技能反推、仅靠 parsed 的 `target_role` 均不得判 `pass`           |
| 结论   | `pass` / `fail` / `doubtful`（有表述但与主业明显拧着）                                          |
| 输出   | `{stem}.profile.md` / `{stem}.profile.json`                                                     |
| 终端   | 打印本项结论与岗位类表述；**退出码 0**（写出即可）；失败说明原因退出码 `1`                      |
| 编排   | **可单独跑**；**完整 `resume` 默认挂入**（排查仍跑）；**不替代** `judge-resume`                 |
| 不做   | 不评排版；不因缺性别硬伤；不把本项写成整份不能投                                                |

## 2. 检查怎么实现

| 编号            | 实现方式       | 说明                                                                  |
| --------------- | -------------- | --------------------------------------------------------------------- |
| **正文来源**    | **规则**       | 有 `resume.norm.md` 则优先；否则 `resume.md` 抽出正文                 |
| **parsed 提示** | **规则**       | 若有 `parsed.json`，把 `target_role` 等作参考；**不得**据此单独过本项 |
| **C1**          | **LLM + 规则** | LLM 初判；`has_homepage_role_phrase` 兜底：首页无表述 → 强制 `fail`   |
| **fixes**       | **LLM / 规则** | ≤2 条可执行改法；规则强制 fail 时补「须写在首页」改法                 |

## 3. 失败约定

| 情况               | 行为                          |
| ------------------ | ----------------------------- |
| 无简历文本等       | 失败说明，退出码 `1`          |
| 写出（含未过本项） | 退出码 `0`；报告标明 `status` |

## 4. 测试

单元测试注入假的 profile assessor；含「工作经历有岗位、首页无」强制 fail；真实密钥与真实简历不进 Git。
