# 查排版技术说明

- **版本**：v0.3
- **日期**：2026-09-04
- **对应工具**：`employ-guard check-layout`
- **标准**：[004 简历合格线 §3](../04-standard/004_resume-bar_简历合格线.md)
- **提示词位置**：`src/employ_guard/check_layout.py` 中 `SYSTEM_PROMPT` / `USER_PROMPT`
- **几何规则**：`src/employ_guard/layout_geometry.py`（页数之外的过密兜底）

## 1. 锁定结论

| 项     | 口径                                                                                  |
| ------ | ------------------------------------------------------------------------------------- |
| 输入   | 投递用 PDF；**必须**已有同次运行目录下的 `pages/`（先跑 `pdf-to-images`）             |
| 看什么 | **只看页图**；不读 `{stem}.resume.md`，不用抽出文字代替版式检查                       |
| 规则层 | **P1** 数页；**过密 / 文字墙**用页图行占用率兜底（视觉漏判时补 `tight_spacing` / P4） |
| 输出   | `{stem}.layout.md` / `{stem}.layout.json`；合格线与水平线分栏；未过时另写「改稿要点」 |
| 终端   | 达标打印「排版达标」；未达标打印「排版未达标」、未过项与改稿要点，退出码 `2`          |
| 不做   | 不判断内容能不能投；不打百分制分数；规则层**不替代**页图视觉检查                      |

## 2. 检查怎么实现

| 编号              | 实现方式                           | 说明                                                                                          |
| ----------------- | ---------------------------------- | --------------------------------------------------------------------------------------------- |
| **P1**            | **规则**（数 `pages/` 内图片张数） | 总页数 ≤ 4；与视觉模型无关                                                                    |
| **过密兜底**      | **规则**（页图扫描行占用率）       | 占用率过高 → 补 `tight_spacing`；更高阈值可拉低 P4；视觉已判出则合并页码，不互相撤销          |
| **P2～P5**        | **视觉模型**看页图                 | 对照 004；校区 / 试用类水印不因 P5 判不合格                                                   |
| **Q1～Q3**        | **视觉模型**（仅合格线全过后写入） | 语义钉死：对齐 / 列表与标题 / 联系方式分区；允许 `signal=false`                               |
| **defects**       | 同一次视觉调用 + 几何兜底          | 行首标点、列表符号不一致、对齐异常、段前段后过密 / 长段墙、字体字号不一致（后者不单独抬未过） |
| **revision_tips** | **规则**                           | 超页、合格线未过或细项成立时给出压页、拆短句、统一字号等；**字体未检出时仍提示人工再看字号**  |

视觉调用：OpenAI 兼容 Chat Completions；页图 base64；`detail=high`；默认模型 `deepseek-v4-flash-vision-exp`（`LLM_VISION_MODEL` 可改）。JSON 中 `geometry` 记录各页行占用率与阈值。

本仓是**固定流程里的一步**，不是自主智能体。

## 3. 失败约定

| 情况                         | 行为                                         |
| ---------------------------- | -------------------------------------------- |
| 不是 PDF / 无页图 / 看图失败 | 失败说明，退出码 `1`；**不**编造排版结论     |
| 工具跑通但合格线未过         | 写出报告；终端明确「排版未达标」；退出码 `2` |

## 4. 测试

单元测试注入假的视觉评估器，覆盖：缺页图、P1 超页、几何过密兜底、写出报告、CLI 达标 / 未达标退出码。真实密钥与真实简历不进 Git。
