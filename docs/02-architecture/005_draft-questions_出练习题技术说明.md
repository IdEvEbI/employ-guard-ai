# 按项目出练习题技术说明

- **版本**：v0.2
- **日期**：2026-09-04
- **对应工具**：`employ-guard draft-questions`
- **产品**：[产品说明 §4.6](../01-product/001_prd_就业守护助手产品说明.md)
- **提示词位置**：`src/employ_guard/draft_questions.py` 中 `SYSTEM_PROMPT`

> 原「扁平 6～8 题」`draft-questions` 已退役；投前看简历的出题步统一为本工具，避免与按项目题重复。

## 1. 锁定结论

| 项     | 口径                                                                |
| ------ | ------------------------------------------------------------------- |
| 输入   | PDF（须已有 `{stem}.resume.md`）或简历 Markdown / 文本              |
| 看什么 | **只看文本**；可选岗位说明                                          |
| 输出   | `{stem}.questions.md` / `{stem}.questions.json`（内容按主项目分组） |
| 终端   | 打印范围、主项目数与题量摘要；**退出码 0**（成功写出即可）          |
| 编排   | `resume` **完整模式**跑本步；`--triage` / `--no-questions` 可关闭   |
| 不做   | 不判能不能投；不评排版；不写成企业真题；不另写第二套扁平题文件      |

报告须声明：题目为推测、仅供练习，不是某家公司的真题。

## 2. 检查怎么实现

| 编号           | 实现方式 | 说明                                                                |
| -------------- | -------- | ------------------------------------------------------------------- |
| **主项目**     | **LLM**  | 识别 1～3 个主项目；须能在简历找到依据                              |
| **basics**     | **LLM**  | 每项目约 5 道；含 `focus`（考察点）与 `follow_ups`（可能追问 1～3） |
| **deep_dives** | **LLM**  | 每项目约 3 道；含 `why`（推测依据）                                 |
| **scope**      | **LLM**  | 无岗位说明时强制「通用技术面，不是某家公司的真题」                  |

LLM：OpenAI 兼容 Chat Completions；JSON 失败时按策略重试。复用 `resolve_resume_text`。

## 3. 失败约定

| 情况         | 行为                 |
| ------------ | -------------------- |
| 无简历文本等 | 失败说明，退出码 `1` |
| 跑通并写出   | 退出码 `0`           |

## 4. 测试

单元测试注入假的 project questions assessor；真实密钥与真实简历不进 Git。
