# 出练习题技术说明

- **版本**：v0.1
- **日期**：2026-09-03
- **对应工具**：`employ-guard draft-questions`
- **产品**：[产品说明 §4.6](../01-product/001_prd_就业守护助手产品说明.md)
- **提示词位置**：`src/employ_guard/draft_questions.py` 中 `SYSTEM_PROMPT`

## 1. 锁定结论

| 项     | 口径                                                           |
| ------ | -------------------------------------------------------------- |
| 输入   | PDF（须已有 `{stem}.resume.md`）或简历 Markdown / 文本         |
| 看什么 | **只看文本**；可选岗位说明                                     |
| 输出   | `{stem}.questions.md` / `{stem}.questions.json`                |
| 终端   | 打印范围与题目前若干条；**退出码 0**（成功写出即可）           |
| 不做   | 不判能不能投；不评排版；不写成企业真题；不写入题库；不打百分制 |

报告须声明：题目为推测、仅供练习，不是某家公司的真题。

## 2. 检查怎么实现

| 编号      | 实现方式 | 说明                                                                   |
| --------- | -------- | ---------------------------------------------------------------------- |
| **题目**  | **LLM**  | 产出 6～8 道；含 category / question / why / focus；须能在简历找到依据 |
| **scope** | **LLM**  | 无岗位说明时强制「通用技术面，不是某家公司的真题」                     |

LLM：OpenAI 兼容 Chat Completions；DeepSeek V4 默认关闭 `thinking`；JSON 失败时按策略重试（与 `judge-resume` 同类）。复用 `resolve_resume_text`。

## 3. 失败约定

| 情况         | 行为                 |
| ------------ | -------------------- |
| 无简历文本等 | 失败说明，退出码 `1` |
| 跑通并写出   | 退出码 `0`           |

## 4. 测试

单元测试注入假的 questions assessor；真实密钥与真实简历不进 Git。
