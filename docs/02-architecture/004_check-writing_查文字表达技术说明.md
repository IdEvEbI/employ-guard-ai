# 查文字表达技术说明

- **版本**：v0.1
- **日期**：2026-09-02
- **对应工具**：`employ-guard check-writing`
- **标准**：[003 简历书写标准 §3.5](../04-standard/003_resume-standard_简历书写标准.md)
- **提示词位置**：`src/employ_guard/check_writing.py` 中 `SYSTEM_PROMPT`

## 1. 锁定结论

| 项     | 口径                                                                 |
| ------ | -------------------------------------------------------------------- |
| 输入   | PDF（须已有 `{stem}.resume.md`）或简历 Markdown / 文本               |
| 看什么 | **只看文本**；对照 003 §3.5（W1～W4）                                |
| 输出   | `{stem}.writing.md` / `{stem}.writing.json`                          |
| 终端   | 无问题打印「文字表达未发现明显问题」；有问题打印待改项，**退出码 0** |
| 不做   | 不判能不能投；不评排版；不出练习题                                   |

W1～W4 **默认不纳入** 004 内容合格线；发现项仅供改稿，不自动等同「不能投」。

## 2. 检查怎么实现

| 编号   | 实现方式       | 说明                                                                  |
| ------ | -------------- | --------------------------------------------------------------------- |
| **W1** | **LLM**        | 错别字、别字；专有名词不误报                                          |
| **W2** | **规则**       | 同一编号列表块内句末标点须一致（分号 / 句号规则）                     |
| **W3** | **规则**       | 中文叙述句中的半角标点；邮箱、URL、版本号、纯英文技能串除外           |
| **W4** | **规则 + LLM** | 口语化、空泛词；超长段 / 超长职责拆短句；技能区「熟练××」模板与未分组 |

LLM：OpenAI 兼容 Chat Completions；DeepSeek V4 默认关闭 `thinking`；JSON 模式失败时按策略重试（与 `judge-resume` 同类）。

## 3. 失败约定

| 情况           | 行为                                     |
| -------------- | ---------------------------------------- |
| 无简历文本等   | 失败说明，退出码 `1`                     |
| 跑通但有待改项 | 写出报告；终端提示待改项；**退出码 `0`** |

## 4. 测试

单元测试注入假的 writing assessor；规则层覆盖列表标点与中英文标点。真实密钥与真实简历不进 Git。
