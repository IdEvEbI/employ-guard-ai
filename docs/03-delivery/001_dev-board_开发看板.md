## 5. 投前看简历 · 排查增强（按序推进）

目标：让更多老师用得起来，并更快排查一摞简历。仍只做简历；**文档先行**，当前 Issue 合入后再开下一件；一次只推进一行。

| ID  | 建议标题                                      | 跟踪 | 验收要点                                                                                        |
| --- | --------------------------------------------- | ---- | ----------------------------------------------------------------------------------------------- |
| R7  | `feat(resume): --force 与 PDF 哈希失效再跳过` | 待开 | 改稿后不会误用旧报告；`--force` 可强制重跑；跳过须对照输入 PDF 哈希                             |
| R8  | `feat(resume): --triage 与教练摘要 brief`     | 待开 | 排查模式默认少跑贵步骤（至少关掉出练习题）；写出短 `{stem}.brief.md`；终端三行结论 + 改法 ≤3 条 |
| R9  | `feat(resume): 出图查排版与读文本路径并行`    | 待开 | `(出图→排版) ∥ (抽文本→文字→判断→题)`；结果与串行一致；失败口径不变                             |
| R10 | `feat(cli): 目录批跑与本地总表`               | 待开 | 对文件夹逐份调用 `resume`；写出本地总表（路径、排版、内容、退出码、brief）；不点名、不上门户    |
| R11 | `docs(onboard): 老师第一次跑通与加强 check`   | 待开 | 半页安装说明；`check` 能提示缺密钥 / 缺依赖；不引入 GUI                                         |
| R12 | `feat(resume): 扫描件 OCR 抽文本`             | 待开 | OCR 只挂在 `read-resume`；失败仍退出码 1，不得写成「不能投」                                    |
| R13 | `feat(convert): Word 转 PDF`                  | 待开 | 独立工具；转换失败不得判内容不合格；本期仍以 PDF 为评价输入                                     |
| R3b | `feat(layout): 几何规则补强查排版`            | 待开 | 页数 / 过密等规则层兜底；不替代页图；排在 OCR / Word 之后评估                                   |

**不做（本阶段）**：听后做复盘；全员自助门户；账号体系；厚 GUI；LangChain / LangGraph；百分制；班级群自动推送。

## 6. 听后做复盘（暂缓）

| ID  | 建议标题                                        | 验收要点                                                                         |
| --- | ----------------------------------------------- | -------------------------------------------------------------------------------- |
| I1  | `feat(asr): 本机转写现场录音`                   | 默认 mlx-whisper `large-v3-turbo`；带时间的逐字稿；不使用云端语音识别            |

| I3  | `feat(review): 面试评价`                        | 用面试作答的检查项，不用简历内容标准；不超过 3 条改法                            |
| I4  | `feat(cli): interview 按顺序调用并跳过已有文件` | 老师一条命令跑完 I1～I3；已有转写稿则跳过转写；`--resume` 须为 PDF；不运行查排版 |

听后做复盘做完的标志：维护者对若干段真面试现场录音跑通 `interview`，问答列表可供师生一起听时当提纲。详见 [产品说明第 11.2 节](../01-product/001_prd_就业守护助手产品说明.md)。**当前暂缓，不插队。**
