# 文档入口（employ-guard-ai）

业务愿景与就业达标尺子在上游私有文档仓。本仓只保留工程所需摘要与契约，避免与上游长期双源漂移。

M0 期间，产品 PRD、架构摘要与交付看板将分 Issue 合入。落地后的阅读顺序：

1. `docs/01-product/`：做什么、不做什么、如何验收
2. `docs/02-architecture/`：怎么做、为什么（含上游标准引用）
3. `docs/03-delivery/`：开发看板与 DevOps
4. `.cursor/rules/`：本仓协作硬约束（公开仓口径）

在对应目录尚未创建前，请先阅读仓库根目录 [README.md](../README.md) 与 GitHub Issue。
